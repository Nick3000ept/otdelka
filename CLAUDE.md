  2026-08-03) — это 190 работ из 321. Итого витрина видит **131 работу**, 20 групп,

## ⚠️ Данные в чат не тянуть (инцидент 2026-08-02)

Ответ `?action=load` — **~980 КБ** (Работы 1139×17, Материалы 273×6, Расходы 1010×13),
это ~300–500 тыс. токенов. Один вывод этого ответа в переписку съедает весь дневной лимит
Claude за один запрос. Боевая «Отделка СБ3 база» (12 МБ) — ещё хуже.

Правила для будущих сессий:
- **Никогда** не печатать ответ `load` (и любой дамп листов) в чат целиком — ни через
  `Invoke-WebRequest`, ни через `WebFetch`, ни через MCP Google Drive.
- Нужно проверить, что бэк жив → запрашивать `?action=ping` (ответ ~60 байт).
- Нужно узнать структуру/объём → выводить только агрегаты: `.Length`, `.Count`,
  список названий колонок. Пример безопасной команды:
  ```powershell
  $r = Invoke-WebRequest -Uri "<URL>?action=load&t=<пароль>" -UseBasicParsing
  "bytes: " + $r.Content.Length
  ($r.Content | ConvertFrom-Json).works.Count
  ```
- Нужно посмотреть примеры строк → максимум 3–5 строк, не весь лист.
- Если данные нужно анализировать всерьёз — сохранять в файл в scratchpad и работать
  запросами по файлу (фильтр/подсчёт), а не читать файл целиком.

## Известные нюансы

- **Новый GAS-проект после `clasp deploy` не сразу доступен анонимно** — даже с `"access": "ANYONE_ANONYMOUS"` в манифесте, реальный доступ пришлось один раз вручную подтвердить в редакторе (Развертывание → Управление развертываниями → карандаш → проверить «У кого есть доступ» → Развернуть). Для существующих проектов (передеплой через `update-deployment`) этот шаг не нужен.
- **`clasp run` не работает** — «Google Apps Script API» не включён для аккаунта `kuzkin@acons.group` (Script function not found / API executable). Функции типа `setup()` в Script Properties приходится запускать вручную через редактор (▷ «Выполнить» → выбрать функцию → авторизовать).
- Если понадобится сменить пароль — поменять в `script.gs` функции `setup()` и один раз выполнить её заново в редакторе, либо вручную через «Настройки проекта → Свойства скрипта» в редакторе GAS.
- GitHub Pages и включение доступа GAS webapp настраивались вручную в вебе (не через API — не было ни `gh` CLI, ни валидного GitHub-токена на момент разработки).
